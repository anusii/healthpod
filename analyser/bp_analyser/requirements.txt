# Dependencies for the HealthPod blood pressure analyser.
#
# grpcio        - the interface the app calls to start an analysis.
# protobuf      - the messages it carries.
# httpx         - HTTP client for the Solid server (DPoP-authenticated).
# cryptography  - AES, RSA and HKDF, matching solidpod's on-Pod formats.
# argon2-cffi   - Argon2id, the first half of solidpod's key derivation.
# rdflib        - parsing the turtle documents a Pod is made of.
# PyYAML        - the configuration file.

# The floors are what the committed bindings in bp_analyser/analyser_pb2.py
# and analyser_pb2_grpc.py were generated against. Newer is fine — protobuf
# guarantees a runtime reads code generated by an older compiler, not the
# other way round — so regenerating with a newer grpcio-tools means raising
# these to match. See proto.sh.

protobuf>=5.28.1
httpx>=0.27
cryptography>=42.0

rdflib>=7.0
PyYAML>=6.0

# Optional, and only needed for the parts that use them:
